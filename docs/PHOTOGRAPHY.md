## Presentation policy

- No current pair is sufficiently aligned for an honest overlay. All nine documented work/result pairs use separate labelled photographs; Project 10 uses **Front view / Side view**, not an unverified before/after claim.
- `Project.presentation` is explicit. Only `aligned` permits the existing accessible slider; no current record has that value. Change it only after reviewing genuinely matching photographs of the same roof face.
- Evidence sequences, fullscreen images and detail galleries preserve the original frame. Preview cards use **reviewed roof-focused crops** with `object-fit: cover`, never stretching. Each project has an explicit `previewPosition`; Project 05 also has a card-only `previewScale`. Original files and complete views remain available. No photograph is synthetically completed, retouched to hide site conditions or substituted with stock imagery.
- The live configurable 3D house leads the home page and is labelled as an illustrative model, not company work. Project 02's anthracite roof and Project 03's brown roof/window detail are the only featured project photos. Project 09's old-tile close-up illustrates the condition-assessment section and is explicitly labelled **before renovation**. No photograph is repeated within the homepage.
- Project 10's scaffolded masonry view is now gallery evidence only. Construction-stage views and the original collage sit behind portfolio documentation disclosures or inside project galleries, not in the hero.
- Project 01's supplied filenames are reversed: source `_2_` is the work-stage photo; `_1_` is the new red roof. The existing corrected mapping is preserved.
